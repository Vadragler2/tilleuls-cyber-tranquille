## Démonstration : kit d'urgence de la mairie

Le bouton **Mode crise** sur le tableau de bord ouvre un kit de première réaction : contacts de crise, trois réflexes, suivi d'une relecture du plan et exercice guidé avec export du bilan.

Il s'agit d'une **démo pédagogique sans véritable sauvegarde, intervention sur serveur ou notification automatique**. Les informations ajoutées sont stockées localement dans le navigateur et ne sont pas partagées entre ordinateurs. Ne saisissez pas de vraies coordonnées dans cette démonstration publique.
